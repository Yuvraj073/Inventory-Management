# Inventory-Management
A beginner-friendly REST API built with FastAPI and Python to practice API development, CRUD operations, request handling, and product management. The project includes endpoints for listing, retrieving, adding, updating, deleting, and searching products.

🚧 Project Status

Under Development — This project is part of my journey to learn FastAPI, database integration, and backend development.

✨ Features

Product Management

Retrieve All Products

Get a Product by ID

Add a New Product

Update an Existing Product

Delete a Product

Product Search

Search Products by Name

Case-Insensitive Search

Partial Name Matching

API Development

REST API Endpoints Using FastAPI

Path and Query Parameters

JSON Request and Response Handling

Python Type Hints

Automatic API Documentation with Swagger UI

Database Setup

SQLAlchemy Session Configuration

Database Engine Configuration

SQLAlchemy Model Integration

Automatic Table Creation

Note: The current product operations use an in-memory Python list. Although database configuration and table creation are present, the endpoints have not yet been connected to persistent database queries.
